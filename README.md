# movie recommend page

## 프로젝트 설명
* 이 프로젝트는 카카오테크캠퍼스 프론트엔드 코스 1차 과제 수행을 위한 프로젝트 입니다. TMDB API를 이용해 영화 정보를 받아와 사용자가 검색을 통해 영화 정보를 확인할 수 있는 웹페이지 입니다.

## 웹페이지 설명
* 처음 웹페이지가 로드되거나, 새로고침이 되면 인기영화 정보를 받아와 화면에 출력합니다. 
* 검색창에 영화 제목을 타이핑하면 0.5초의 시간지연 후에 키워드를 포함하는 영화 제목이 출력됩니다. "검색"버튼을 누르거나 엔터를 누르면 검색 키워드를 포함하는 영화카드들이 출력됩니다. 
* 영화 카드를 클릭하면 영화 상세정보를 모달을 통해 보여줍니다. 
* 영화 카드에 있는 하트 버튼을 누르면 그 영화가 '좋아요'표시 됩니다. 좋아요한 영화들은 '좋아요한 목록 보기' 버튼을 누르면 화면에 출력됩니다.

## 사용된 기술 스택
* HTML
* CSS
* JavaScript

## API 키에 관한 정보
* config.js 파일에 TMDB API키를 하드코딩해서 구현했습니다.
* github에 push할 때 config.js 파일은 제외했습니다.
* config-template.js 파일을 통해 config.js 파일의 템플릿을 올렸습니다.
